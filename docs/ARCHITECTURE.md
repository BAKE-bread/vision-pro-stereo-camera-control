# 会话与设备生命周期

会话使用代次标识，停止后不会被旧异步结果重新激活。三个功能页留在一个原生 App 内，状态所有权按会话划分。

## Apple 客户端

| 对象 | 负责内容 | 停止或失效时 |
|---|---|---|
| `RemoteModel` | 服务器配置、能力查询与会话协调 | 同步更新会话编号，取消待完成查询，随后停止子会话 |
| `StereoVideoSession` | LiveKit 房间、发布者/轨道筛选、帧时效 | 关闭旧帧邮箱、卸载回调、停止真实头部跟随；深度会话继续 |
| `ControlSession` | 控制权申请、姿态、逐条指令和确认 | 关闭对应通道和 ARKit 实例；迟到租约不能影响新会话 |
| `WebSocketControlChannel` | JSON 收发及每次 I/O 的 1.2 秒截止时间 | 超时关闭 WebSocket，不让客户端无限显示正在控制 |
| `HeadPose` | 每次启动创建全新的 ARKit session/provider，姿态基准与滤波 | 停止并释放本次实例，授权期间停止也无法恢复旧实例 |
| `DepthSession` | 快照轮询、时效、固定测量帧及有限历史 | 清空实时快照、取消当前测量；历史记录明确保留来源和帧号 |
| `LibraryModel` | 播放意图、AVPlayer 回调、断点位置、导入进度 | 暂停后迟到的就绪/seek 回调不会重新播放 |
| `MediaLibraryStore` / `MediaImporter` | 清单读写、路径校验、受限文件访问和协调复制 | 清单损坏时保留原文件；未完成的复制不加入播放列表 |

所有界面状态在 MainActor 上更新。实时视频回调只持有容量为一的线程安全帧邮箱，不创建无限量主线程任务。替换视频轨道时同时替换邮箱，迟到回调无法重新填充已经关闭的邮箱。

### 双目渲染

先验证轨道发布者、轨道名称、top-bottom 布局、无旋转和精确尺寸，再将上半帧交给左眼、下半帧交给右眼。Core Image 写入 `rgba16Float` 线性纹理，经 `LowLevelTexture.replace(using:)` 与 RealityKit 同步。使用可抛错的 `startTask`，等待 GPU 完成后才显示新帧；最多一帧转换在途，解码端保留最新帧。

测试会从 GPU 纹理读回像素验证上红下蓝的左右分配。该测试不等同于真机双眼 camera-index、垂直方向或色彩舒适度验收。沉浸屏幕默认固定在房间坐标，避免持续把大屏锁在头上。

参考：[Apple CIRenderDestination](https://developer.apple.com/documentation/coreimage/cirenderdestination/init%28mtltexture%3Acommandbuffer%3A%29-2iu5i)、[Core Image 可抛错渲染](https://developer.apple.com/documentation/coreimage/cicontext/starttask%28torender%3Ato%3A%29)。

### 测距语义

实时快照超过 750 ms 时失效。点选后固定当时的画面与选点，测量请求使用同一个 frame_id，结果不叠加到之后的直播帧。历史只在内存中保留最近 20 条，含时间、服务器地址、快照与测量结果。返回实时画面后，迟到的测量响应被忽略。

### 媒体库

旧的 library.json 兼容读取；新增的播放位置和时长均为可选字段。每五秒及暂停时保存有限时长媒体的进度，结束时清零；实时流不伪造断点。文件通过 NSFileCoordinator 在受限访问期间分块复制，完成后再写入清单。原始文件、损坏清单和失败复制均不自动删除。

## Python 服务端

相机与云台各有一个 `DeviceWorker`。设备构造、采集/移动、关闭均排在同一专用线程中；取消等待任务不会取消正在执行的 SDK 调用，关闭必须排在其后。服务停止后先拒绝新控制，再等待在途操作并关闭设备。

应用层只读取云台的初始角度及角度范围，不解释寄存器 tick。一次移动在写入任何轴之前验证全部角度；故障关闭会尝试停用所有已启用轴并关闭端口，即使其中一轴失败。

ZED 检查 grab、左右目提取和深度提取的所有返回码、数组尺寸/类型及内参。任何失败都不递增帧号；复制深度缓冲后再生成 Frame。最新帧保留 RGBD，历史测量缓存只保留深度与内参。

## 明确保留的边界

- Python 不能强制安全中断永不返回的厂商 SDK 调用。当前选择等待，而不是并发关闭正在使用的设备；ZED 使用异步恢复；云台配置总线看门狗；设备关闭分别排队，互不等待。
- 云台状态是限速后的指令角度；驱动检查编码器边界，不提供连续编码器遥测或独立急停。
- 原生网络测试使用本机 mock 服务；ZED、真实云台、Vision Pro 追踪与眼别需要独立验收。
- 程序范围为双目平面视频、深度和双轴控制，不包含全景、3DGS、六自由度重投影或训练环境。
